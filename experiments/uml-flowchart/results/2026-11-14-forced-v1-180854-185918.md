# 强制图像输入：首次完整对照结果

两组均通过全部 11 个评分测试，得分 1；两组输入传递检查均通过。加图组 7 次任务模型请求，每次均含两张 PNG，且位于与纯文本组相同的两份完整原文之前。

| 指标 | 纯文本组 | 加图组 |
|---|---:|---:|
| 工具调用步数 | 19 | 8 |
| 任务模型调用次数 | 15 | 7 |
| 轨迹事件数（含用户、思考和回答） | 35 | 15 |
| 输入 token | 482,123 | 159,190 |
| 其中缓存命中 token | 450,176 | 142,464 |
| 未缓存输入 token | 31,947 | 16,726 |
| 输出 token | 9,273 | 2,138 |
| 总 token | 491,396 | 161,328 |
| Agent 执行时间（秒） | 64.6 | 15.7 |
| 完整运行时间（秒，含环境与评分） | 167.7 | 98.5 |
| 框架估算费用（美元） | 0.023412756 | 0.008438184 |

本次观察：工具调用减少 57.9%，总 token 减少 67.2%，Agent 执行时间减少 75.7%。

工具轨迹中，纯文本组先多次探查晶体结构、对称性与输出约定，较晚读取 Wyckoff 文字参考；加图组第 3 次工具调用就读取该参考，随后实现和验证。两组均未出现失败工具调用。这个执行路径差异与减少探索相符，但不能单独证明视觉模态导致改善。

token 为整次运行累计，包含两组各一次自动标题调用；缓存命中已包含在输入中。接口未单列图像 token。费用仅为框架估算，不代表账单。比较 Agent 耗时用 agent_execution；完整运行时间另含约 82/72 秒的评分等待，不应全部归因于模型。

这只是一项任务、每组一次，未指定随机种子；还需要重复实验。图像本身提炼了 skill 内容，当前测量的是“流程图摘要＋视觉输入”的整体影响，无法分离视觉与同内容文字摘要的作用。新结果不能与此前未实际传图的旧组混用。
